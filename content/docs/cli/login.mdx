---
title: euthyne login
description: Sign in from the terminal.
---

<Callout title="Coming soon">Planned command. Not released yet.</Callout>

```bash
euthyne login
```

Signs you in with the OAuth device flow (RFC 8628). The CLI shows a code and a link. You confirm the code in your browser with your GitHub account.

The device token is stored in your OS keychain. It can only upload receipts for your own device.

[`init`](/docs/cli/init) runs `login` for you when needed.
