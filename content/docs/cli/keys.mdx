```bash
euthyne keys rotate
```

`rotate` will create a new device key. The old key signs the new one, a key event is written to the log, and Euthyne issues a new credential for the new key.

`export-commitment-key` will let your organization keep its own copy of the commitment key, encrypted to a recipient you choose. Euthyne never holds it.

Revoking a key will be done from the dashboard. Revocation is logged at a given log index. Later receipts signed with that key are rejected and fail verification. Earlier receipts stay valid, with a note.
