`euthyne` is a single binary. It records what Claude Code does through hooks, signs receipts on your machine, uploads them, and verifies them offline.

It is not published yet. A Homebrew tap and an install script are planned. During the preview, we send you a build. It runs on macOS and Linux.

## Commands

| Command | What it does |
| --- | --- |
| [`init`](/docs/cli/init) | Asks for your consent, enrols this machine, installs the hooks in the current repository and, if you agree, the telemetry lines for tokens and cost |
| [`hook`](/docs/cli/hook) | Called by Claude Code on each hook event. Signs one receipt |
| [`sync`](/docs/cli/sync) | Uploads queued mandates and receipts, then saves their log proofs |
| [`verify`](/docs/cli/verify) | Checks a receipt bundle offline |
| [`mandate show`](/docs/cli/mandate) | Prints the mandates captured for a session |
| [`reveal`](/docs/cli/reveal) | Opens one committed field of a receipt for an auditor |
| [`uninstall`](/docs/cli/uninstall) | Removes exactly what `init` wrote |

Planned, not built yet: [`login`](/docs/cli/login), [`status`](/docs/cli/status), [`keys`](/docs/cli/keys) and [`mcp`](/docs/cli/mcp).

Run `euthyne --help` or `euthyne <command> --help` for the exact usage of your build.

## Global flags

Every command takes these flags.

| Flag | Environment variable | Effect |
| --- | --- | --- |
| `--home` | `EUTHYNE_HOME` | State directory. Defaults to `~/.local/share/euthyne`, or `$XDG_DATA_HOME/euthyne` when set |
| `--keystore` | `EUTHYNE_KEYSTORE` | Where device keys live: `keychain` (default) or `file` |
| `--log-key` | `EUTHYNE_LOG_KEY` | A log verifier key to trust instead of the one built into the binary. The CLI warns when you override it |

## Keys and state

The device key, the commitment key and the device token live in your OS keychain. With `--keystore file`, they go to files under `<home>/keys` that only you can read.

The state directory holds the CLI's config, the upload queue, saved receipt bundles, the mandates of your sessions and the checkpoints this machine has seen. It is created readable by you only.
