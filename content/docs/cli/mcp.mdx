<Callout title="Soon">Not built yet. The CLI has no `mcp` command today.</Callout>

```bash
euthyne mcp
```

It will start an MCP server over stdio, reading your API key from the keychain or from `EUTHYNE_API_KEY`.

Every tool will be read-only. None will return mandates or check results: agents never see their mandate. See [MCP](/docs/mcp) for the setup and tool list we plan.
