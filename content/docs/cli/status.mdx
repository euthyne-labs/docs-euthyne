<Callout title="Planned">Not built yet. Until it ships, [`sync`](/docs/cli/sync) tells you what it uploaded and what is still waiting.</Callout>

```bash
euthyne status
euthyne status --json
```

It will show your organization and device, the hooks found per harness, how many receipts are waiting to upload, the last sync and the last error.

`--json` will print machine-readable output for scripts.
